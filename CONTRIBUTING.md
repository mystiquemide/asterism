# Contributing

Thanks for your interest in Asterism.

## How to contribute

1. Fork the repo
2. Create a branch (`git checkout -b feature/your-idea`)
3. Commit your changes (`git commit -m 'Add something'`)
4. Push to the branch (`git push origin feature/your-idea`)
5. Open a pull request

## What we're looking for

- New specimens for Family VIII
- Improvements to the Hopfield recall or CRT treatment
- Accessibility improvements
- Bug fixes

## Code style

- Vanilla HTML/CSS/JS — no framework dependencies
- Keep everything in a single file per page
- Match the existing CRT parameter conventions
- Test across browsers before submitting

## Questions?

Open an issue or reach out to [@MystiqueMide](https://x.com/MystiqueMide).
